Fisher summary

BAP1-KO mCH downstream analyses 25 section scripts across 8 thematic groups. Run on corrected edgeR results (lambda as covariate).

Each section sources _shared_config.R, which pre-loads the mCH differential results (21,097 testable genes, 5,557 at FDR < 0.05), all DiffBind tables, consensus peaks, and shared helper functions. Gene-level Fisher tests go through register_fisher_test(), which writes per-test shards to a central registry. 165 tests registered across all sections.

Core pipeline results (steps 01-08) are in the companion pipeline_walkthrough.html.

10_01: Chromatin state classification

method Each gene classified into a promoter state and a body state by overlapping CUT&RUN consensus peak BEDs from data/chip_peaks/. Body state uses H3K27ac, H3K27me3, H3K4me1 (priority: Mixed, Polycomb, Active, Enhancer_Marked, Unmarked). Promoter state uses H3K4me3, H3K27me3, H3K27ac, Bivalent (priority: Bivalent, Active, Repressed, Unmarked). Fisher exact test per state, BH-adjusted.

40_01: DMR x marks permutation

method regioneR spatial permutation (5,000 shuffles, per-chromosome, unmasked, using BSgenome.Mmusculus.UCSC.mm10 for chromosome lengths). Query: mCH hyper and hypo gene bodies. Targets: 8 peak sets (ATAC up/down, K119ub gained/lost, K27ac gained/lost, MeCP2 up/down). 16 permutation cells + 24 gene-level Fisher tests. Concordance between Fisher ORs and permutation Z-scores validates that gene-level associations are not region-size artifacts.
Permutation Z-scores. Each row: mCH hyper/hypo gene bodies vs a ChIP mark's gained/lost peaks.
x: Fisher OR (gene-level). y: permutation Z-score. Tests concordance.

40_02: ATAC x features permutation

method Four sub-analyses: ATAC x 6 consensus mark peaks, ATAC x 5 body states, ATAC x 4 promoter states, loop anchors x 12 feature sets. Same regioneR framework as 40_01. crosswisePermTest + local Z-scores.
Fisher vs permutation concordance for ATAC x features tests.

40_03: Domain permutation

method Query: mCH hyper/hypo gene bodies. Targets: A/B compartment domains (HOMER, merged), B-to-A/A-to-B shifts, H3K27me3 domains (consensus peaks merged at 5 kb gap), Polycomb-state gene bodies. Same regioneR framework. Local Z-scores computed.

60_03: Peak reconciliation

method Compares two gene-level collapse rules: nearest-TSS vs median-of-significant. Signal mass = peak width × 2Conc (linear-scale concentration). Peak properties compared between gained and lost peaks. Three GSEA runs (GO BP) on different gene rankings.

The "collapse rule" converts multiple DiffBind peaks per gene into one gene-level fold change. The nearest-TSS rule picks the peak closest to the TSS. The median-significant rule takes the median fold of peaks passing FDR < 0.05.
